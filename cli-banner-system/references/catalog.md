# CLI Banner Catalog

## Category 1: ASCII Art Classic
- FIGlet/TOIlet style
- Tools: figlet, toilet
- Compatible with any terminal

## Category 2: Blocks (Solid)
- Unicode block characters (█, ▓, ▒, ░)
- Modern and professional look
- Requires UTF-8 terminal

## Category 3: Minimalist Lines
- Box-drawing (┌, ┐, └, ┘, │, ─)
- Simple lines (═, ─, =)
- Clean and professional

## Category 4: ANSI Colors
- Gradient colors
- Rainbow
- Requires ANSI support

## Category 5: System Info (Neofetch style)
- OS info, kernel, uptime
- Adaptable to app info

## Category 6: Animated
- Typing effect
- Fade in/out
- ASCII animation frames

## Category 7: Emoji and Unicode Symbols
- Emoji art
- Decorative symbols (★, ✦, ◆)

## Category 8: Copilot / Modern
- Rounded borders (╭, ╮, ╰, ╯)
- Minimalist with gradient
- Modern professional look

## Category 9: Dashboard / Real-time Data
- Status, time, files processed
- Memory, uptime

## Selection Criteria
- Business/serious apps → Box-drawing, Info app
- Creative/entertainment → Emoji art, Rainbow, Animated
- Dev/DevOps tools → Copilot style, Neofetch, Dashboard
- Old terminals → ASCII art, Simple lines
- Modern terminals → Unicode art, Colors, Emojis
