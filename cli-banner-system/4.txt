## Skill: Sistema Universal de Banners CLI - Catálogo Completo y Generador Adaptativo

**Descripción General:**
Implementar un sistema universal de generación y selección de banners para aplicaciones CLI que incluya todos los estilos existentes, permitiendo elegir el tipo de banner más adecuado según el contexto, tecnología y propósito de la aplicación. Este skill debe integrarse con el **Skill de Bootstrap Inteligente** para mostrarse durante el arranque de la app.

---

### **Fase 1: Catálogo Completo de Tipos de Banners**

#### **Categoría 1: ASCII Art Clásico (Caracteres Estándar)**

**1.1 Estilo FIGlet/TOIlet (Texto grande con caracteres)**
```
  _____ _           _   _      ____  
 / ____| |         | | | |    |___ \ 
| |    | |__   __ _| |_| |__    __) |
| |    | '_ \ / _` | __| '_ \  |__ < 
| |____| | | | (_| | |_| | | | ___) |
 \_____|_| |_|\__,_|\__|_| |_| |____/ 
```

**Características:**
- Hecho con caracteres ASCII estándar (#, @, %, &, *, etc.)
- Fácil de crear con herramientas como `figlet`, `toilet`

- Múltiples fuentes disponibles (standard, banner, big, block, etc.)

**Herramientas para crearlo:**
- `figlet` (estándar)
- `toilet` (con colores)
- Generadores online como patorjk.com/figlet

### **Fase 2: Herramientas y Librerías para Crear Banners**

#### **Herramientas de Línea de Comandos:**

**FIGlet (ASCII Art clásico):**
```bash
figlet "Mi App"
figlet -f banner "Mi App"
figlet -f block "Mi App"
```

**TOIlet (FIGlet con colores):**
```bash
toilet "Mi App"
toilet -f mono12 -F gay "Mi App"
```

**Cowsay (Mensaje con vaca):**
```bash
cowsay "Hola Mundo"
cowsay -f dragon "Hola Mundo"
```

**Neofetch (Info del sistema):**
```bash
neofetch
neofetch --ascii_distro ubuntu
```

### **Fase 3: Sistema de Selección Inteligente de Banner**

#### **3.1 Criterios de Selección Automática:**

El sistema debe sugerir el tipo de banner según:

**Tipo de Aplicación:**
- **Apps empresariales/serias** → Box-Drawing, Minimalista con líneas, Info de la App
- **Apps creativas/entretenimiento** → Emoji Art, Rainbow, Animados
- **Apps de desarrollo/DevOps** → Estilo Copilot, Neofetch, Dashboard
- **Apps educativas** → Bloques sólidos, Colores ANSI, Emoji Art

**Plataforma/Destino:**
- **Terminales antiguas** → ASCII Art clásico, Líneas simples (solo caracteres básicos)
- **Terminales modernas** → Unicode art, Colores ANSI, Emojis
- **Web terminals** → Box-Drawing, Colores ANSI (limitado)

**Contexto de Uso:**
- **Uso frecuente** → Minimalista (rápido de renderizar)
- **Primera impresión/demo** → Animado, Gradiente, Impactante
- **Producción/servidor** → Info de la App, Dashboard (informativo)

**Marca/Identidad:**
- **Con logo definido** → Logo ASCII personalizado
- **Sin identidad visual** → FIGlet con nombre de la app
- **Marca moderna** → Estilo Copilot, Minimalista

---

#### **3.2 Sistema de Configuración del Banner:**

El sistema debe permitir configurar:

**Archivo de configuración (`banner.config.json`):**
```json
{
  "type": "box-drawing",
  "title": "Mi App CLI",
  "subtitle": "Gestión Inteligente",
  "version": "1.0.0",
  "showInfo": true,
  "info": {
    "author": "Tu Nombre",
    "license": "MIT",
    "node": "auto"
  },
  "colors": {
    "primary": "#00ff00",
    "secondary": "#0088ff",
    "background": "transparent"
  },
  "animation": false,
  "border": "rounded"
}
```

### **Fase 4: Integración con el Bootstrap**

#### **4.1 Flujo de Trabajo:**

```
1. Usuario ejecuta: ./start.sh
2. Sistema detecta si es primera ejecución
3. Si es primera vez:
   ├─ Muestra loader de bootstrap
   ├─ Al finalizar, pregunta: "¿Qué estilo de banner prefieres?"
   ├─ Muestra ejemplos de cada tipo
   ├─ Usuario selecciona su preferencia
   └─ Guarda configuración en banner.config.json
4. Si ya está configurado:
   ├─ Carga configuración
   └─ Muestra el banner seleccionado
5. Continúa con el menú principal
```

#### **4.2 Comando para Cambiar Banner:**

```bash
./start.sh --banner-config
```

Esto abre un asistente interactivo para:
- Ver ejemplos de todos los tipos
- Seleccionar nuevo estilo
- Personalizar colores, texto, etc.
- Guardar nueva configuración

### **Fase 5: Ejemplos de Implementación**

#### **Ejemplo 1: Banner Box-Drawing con Rich (Python)**

```python
from rich.console import Console
from rich.panel import Panel
from rich.text import Text

console = Console()

banner = Text()
banner.append("🚀 MI APP CLI\n", style="bold green")
banner.append("Gestión Inteligente de Datos\n", style="blue")
banner.append("Versión 1.0.0", style="dim")

console.print(Panel(banner, border_style="green", padding=(1, 2)))
```

**Resultado:**
```

│ 🚀 MI APP CLI                        │
│ Gestión Inteligente de Datos         │
│ Versión 1.0.0                        │
│                                      │

```
