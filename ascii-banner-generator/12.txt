## Skill: Terminal ASCII Banner Generator - Generador Universal de Banners con Alfabeto Completo

**Descripción General:**
Implementar una skill global y reutilizable llamada **Terminal ASCII Banner Generator** para generar banners dinámicos en aplicaciones CLI, basada en un catálogo completo de glifos que cubra el alfabeto latino completo (A-Z, a-z), números (0-9), símbolos de puntuación y caracteres especiales frecuentes, incluyendo soporte para letras acentuadas (Á, É, Í, Ó, Ú, Ü, Ñ y sus minúsculas); cada carácter debe representarse como una matriz de varias filas con altura uniforme (preferiblemente fuentes de 3, 5 y 7 filas), donde cada posición contenga un carácter visual como `█`, `▓`, `░`, `#`, `@`, `*`, `╔`, `═`, `║`, `╚` o espacios; el motor debe convertir cualquier texto en una lista de líneas ASCII uniendo horizontalmente los glifos con espaciado configurable, sustituyendo caracteres no soportados por `?` o celda vacía; debe exponer una configuración rica con campos como `text`, `font`, `height`, `spacing`, `theme`, `colors`, `gradient`, `alignment`, `max_width`, `padding`, `border`, `icon`, `subtitle`, `version`, `url`, `animation`, `speed`, `interactive` y `unicode`, permitiendo crear banners simples, profesionales, retro, tecnológicos, de fuego, minimalistas o multicolor; debe incluir un motor de composición que calcule el ancho real visible ignorando códigos ANSI, emojis y secuencias de color, para centrar correctamente, adaptar al tamaño de terminal, reducir o dividir si excede el ancho disponible, y construir opcionalmente marcos con caracteres Unicode de box-drawing; debe incorporar un sistema de temas con colores por letra, fila, palabra o sección usando estilos como rojo, amarillo, cyan, verde, magenta, blanco, brillante, atenuado y degradados, con soporte para `NO_COLOR`, detección de TTY y modo ASCII seguro; debe proporcionar funciones reutilizables `render_banner(text, config)`, `show_animated_banner(config)`, `show_simple_banner(config)`, `show_tagline(text, config)` y `show_goodbye(config)`, además de animaciones por carácter, línea, bloque, aparición progresiva, escritura instantánea y modo silencioso para CI o redirecciones; debe separar catálogo de glifos, fuentes, temas, motor de composición, sistema de alineación, renderizador, detección de terminal y animación para que cada componente sea sustituible o ampliable independientemente; debe permitir que cada proyecto agregue sus propios glifos, iconos, logotipos o temas sin modificar el núcleo; debe incluir validaciones para comprobar altura uniforme, ancho válido por fila, ausencia de incompatibilidades, límites de ancho y preservación de alineación con colores; debe incluir pruebas unitarias para cada letra, números, símbolos, composición de palabras, centrado con Unicode, modo sin color, terminales pequeñas, animación desactivada y compatibilidad con salida redirigida; y debe documentar ejemplos para generar nombres como `IMG2PDF`, `FLARE-DF`, `MY-CLI` y cualquier texto personalizado, con una fuente predeterminada de 5 o 7 filas, alfabeto completo listo para usar, selección de fuentes y temas desde CLI, archivo de configuración o variables de entorno, entregando una skill que genere banners rápidos, consistentes, adaptables, visualmente atractivos y reutilizables en cualquier aplicación de terminal.

---

### **Fase 1: Arquitectura del Sistema**

#### **1.1 Componentes Principales:**

**GlyphCatalog (Catálogo de Glifos):**
- Almacena la definición visual de cada carácter
- Organizado por fuente (3, 5, 7 filas)
- Permite registrar glifos personalizados
- Incluye fallback para caracteres desconocidos
- Soporta Unicode completo (UTF-8)

**FontManager (Gestor de Fuentes):**
- Gestiona múltiples fuentes disponibles
- Permite cambiar fuente en runtime
- Carga fuentes desde archivos externos
- Incluye fuentes built-in: `standard`, `block`, `slim`, `retro`, `tech`, `minimal`, `shadow`, `fire`

**CompositionEngine (Motor de Composición):**
- Une glifos horizontalmente con espaciado configurable
- Calcula ancho real visible (ignora ANSI)
- Maneja alineación (izquierda, centro, derecha)
- Aplica padding y bordes
- Divide texto largo en múltiples líneas si es necesario

**ThemeSystem (Sistema de Temas):**
- Asigna colores por letra, fila, palabra o sección
- Soporta colores ANSI estándar y 256 colores
- Soporta gradientes y degradados
- Respeta `NO_COLOR` y detección de TTY
- Incluye temas predefinidos

**AnimationEngine (Motor de Animación):**
- Controla velocidad y tipo de animación
- Tipos: por carácter, por línea, por bloque, aparición progresiva, escritura instantánea
- Respeta cancelaciones del usuario
- Limpia pantalla correctamente
- Vacía buffer de salida

**TerminalDetector (Detector de Terminal):**
- Detecta si es TTY o pipe/redirección
- Detecta soporte de Unicode
- Detecta soporte de colores (16, 256, truecolor)
- Detecta ancho de terminal
- Detecta variables como `NO_COLOR`, `CI`, `TERM`

**BannerRenderer (Renderizador):**
- Componente final que ensambla todo
- Expone API pública simple
- Coordina todos los componentes

---

### **Fase 2: Catálogo Completo de Glifos**

#### **2.1 Estructura de un Glifo:**

Cada glifo se define como un array de strings, donde cada string es una fila del carácter. Todas las filas deben tener el mismo ancho.

```typescript
interface Glyph {
  char: string;           // Carácter que representa
  rows: string[];         // Array de filas (altura uniforme)
  width: number;          // Ancho del glifo
  height: number;         // Altura (igual para todos en la misma fuente)
}
```

### **Fase 3: Configuración del Banner**

#### **3.1 Objeto BannerConfig Completo:**

```typescript
interface BannerConfig {
  // Contenido
  text: string;                    // Texto principal del banner
  subtitle?: string;               // Subtítulo debajo del texto
  version?: string;                // Versión a mostrar
  url?: string;                    // URL a mostrar
  icon?: string;                   // Icono/emoji a mostrar
  
  // Fuente y estilo
  font: 'standard' | 'block' | 'slim' | 'retro' | 'tech' | 'minimal' | 'shadow' | 'fire' | string;
  height?: 3 | 5 | 7;              // Altura preferida de la fuente
  spacing?: number;                // Espacio entre caracteres (default: 1)
  
  // Tema y colores
  theme?: 'default' | 'retro' | 'tech' | 'fire' | 'ocean' | 'forest' | 'neon' | 'minimal' | string;
  colors?: ColorConfig;            // Configuración personalizada de colores
  gradient?: GradientConfig;       // Configuración de degradado
  
  // Layout
  alignment?: 'left' | 'center' | 'right';  // Alineación (default: center)
  maxWidth?: number;               // Ancho máximo (default: terminal width)
  padding?: PaddingConfig;         // Padding interno
  border?: BorderConfig;           // Borde del banner
  
  // Animación
  animation?: 'none' | 'typewriter' | 'fade' | 'slide' | 'wave' | 'block';
  speed?: number;                  // Velocidad en ms (default: 50)
  interactive?: boolean;           // Si es interactivo (default: true si TTY)
  
  // Compatibilidad
  unicode?: boolean;               // Forzar uso de Unicode (default: auto-detect)
  noColor?: boolean;               // Desactivar colores (default: auto-detect)
  silent?: boolean;                // Modo silencioso (default: false)
}
```

### **Fase 4: Motor de Composición**

#### **4.1 Algoritmo de Composición:**

```typescript
function composeBanner(text: string, config: BannerConfig): string[] {
  const font = getFont(config.font, config.height);
  const lines: string[] = [];
  
  // 1. Dividir texto en líneas si excede maxWidth
  const textLines = splitTextToFit(text, config.maxWidth, font);
  
  // 2. Para cada línea de texto
  for (const textLine of textLines) {
    // 3. Obtener glifos de cada carácter
    const glyphs = textLine.split('').map(char => getGlyph(char, font));
    
    // 4. Unir glifos horizontalmente con spacing
    const height = glyphs[0].height;
    for (let row = 0; row < height; row++) {
      let line = '';
      for (let i = 0; i < glyphs.length; i++) {
        line += glyphs[i].rows[row];
        if (i < glyphs.length - 1) {
          line += ' '.repeat(config.spacing || 1);
        }
      }
      lines.push(line);
    }
    
    // 5. Separador entre líneas de texto
    lines.push('');
  }
  
  // 6. Aplicar padding
  const paddedLines = applyPadding(lines, config.padding);
  
  // 7. Aplicar alineación
  const alignedLines = applyAlignment(paddedLines, config.alignment, config.maxWidth);
  
  // 8. Aplicar borde si está habilitado
  const borderedLines = config.border?.enabled 
    ? applyBorder(alignedLines, config.border)
    : alignedLines;
  
  // 9. Agregar subtítulo, versión, URL si existen
  const finalLines = addMetadata(borderedLines, config);
  
  return finalLines;
}
```

#### **4.2 Cálculo de Ancho Visible (Ignorando ANSI):**

```typescript
function getVisibleWidth(line: string): number {
  // Eliminar códigos ANSI de color
  const withoutAnsi = line.replace(/\x1b\[[0-9;]*m/g, '');
  // Eliminar secuencias de escape
  const withoutEscape = withoutAnsi.replace(/\x1b\[[0-9;]*[A-Za-z]/g, '');
  // Contar caracteres (considerando Unicode)
  return [...withoutEscape].length;
}
```

#### **4.3 Alineación:**

```typescript
function applyAlignment(lines: string[], alignment: string, maxWidth: number): string[] {
  return lines.map(line => {
    const visibleWidth = getVisibleWidth(line);
    const padding = maxWidth - visibleWidth;
    
    switch (alignment) {
      case 'left':
        return line;
      case 'right':
        return ' '.repeat(padding) + line;
      case 'center':
      default:
        const leftPad = Math.floor(padding / 2);
        return ' '.repeat(leftPad) + line;
    }
  });
}
```

#### **4.4 Bordes con Box-Drawing:**

```typescript
const BORDER_STYLES = {
  'single': { tl: '┌', tr: '┐', bl: '└', br: '┘', h: '─', v: '│' },
  'double': { tl: '╔', tr: '╗', bl: '╚', br: '╝', h: '═', v: '║' },
  'rounded': { tl: '╭', tr: '╮', bl: '╰', br: '╯', h: '─', v: '│' },
  'bold': { tl: '┏', tr: '┓', bl: '┗', br: '┛', h: '━', v: '┃' },
  'ascii': { tl: '+', tr: '+', bl: '+', br: '+', h: '-', v: '|' }
};

function applyBorder(lines: string[], border: BorderConfig): string[] {
  const style = BORDER_STYLES[border.style || 'single'];
  const maxWidth = Math.max(...lines.map(getVisibleWidth));
  
  const result: string[] = [];
  
  // Borde superior
  result.push(style.tl + style.h.repeat(maxWidth + 2) + style.tr);
  
  // Líneas con borde lateral
  for (const line of lines) {
    const padding = maxWidth - getVisibleWidth(line);
    result.push(`${style.v} ${line}${' '.repeat(padding)} ${style.v}`);
  }
  
  // Borde inferior
  result.push(style.bl + style.h.repeat(maxWidth + 2) + style.br);
  
  return result;
}
```

### **Fase 5: Sistema de Colores y Temas**

#### **5.1 Aplicación de Colores:**

```typescript
function applyColors(lines: string[], config: BannerConfig): string[] {
  // Si NO_COLOR está activo o no es TTY, no aplicar colores
  if (config.noColor || !isTTY()) {
    return lines;
  }
  
  const theme = THEMES[config.theme || 'default'];
  
  // Aplicar colores según configuración
  return lines.map((line, index) => {
    let coloredLine = line;
    
    // Color por letra
    if (config.colors?.perLetter) {
      coloredLine = colorByLetter(line, config.colors.letters);
    }
    // Color por fila
    else if (config.colors?.perRow) {
      coloredLine = color(line, config.colors.rows[index % config.colors.rows.length]);
    }
    // Color uniforme
    else if (theme.colors?.text) {
      coloredLine = color(line, theme.colors.text);
    }
    
    // Aplicar gradiente si está configurado
    if (config.gradient) {
      coloredLine = applyGradient(line, config.gradient, index, lines.length);
    }
    
    return coloredLine;
  });
}
```

#### **5.2 Gradientes:**

```typescript
function applyGradient(line: string, gradient: GradientConfig, rowIndex: number, totalRows: number): string {
  const chars = [...line];
  const result: string[] = [];
  
  for (let i = 0; i < chars.length; i++) {
    let colorIndex: number;
    
    switch (gradient.type) {
      case 'horizontal':
        colorIndex = Math.floor((i / chars.length) * gradient.colors.length);
        break;
      case 'vertical':
        colorIndex = Math.floor((rowIndex / totalRows) * gradient.colors.length);
        break;
      case 'rainbow':
        colorIndex = i % gradient.colors.length;
        break;
      case 'fire':
        // Degradado de rojo (abajo) a amarillo (medio) a blanco (arriba)
        const firePosition = (totalRows - rowIndex) / totalRows;
        colorIndex = Math.floor(firePosition * gradient.colors.length);
        break;
      default:
        colorIndex = 0;
    }
    
    const colorName = gradient.colors[Math.min(colorIndex, gradient.colors.length - 1)];
    result.push(color(chars[i], colorName));
  }
  
  return result.join('');
}
```

```typescript
function detectTerminalCapabilities(): TerminalCapabilities {
  const isTTY = process.stdout.isTTY;
  const noColor = process.env.NO_COLOR !== undefined;
  const ci = process.env.CI !== undefined;
  const term = process.env.TERM || '';
  const colorterm = process.env.COLORTERM || '';
  
  // Detectar soporte de colores
  let colorSupport: 'none' | 'basic' | '256' | 'truecolor' = 'none';
  if (!noColor && isTTY && !ci) {
    if (colorterm === 'truecolor' || colorterm === '24bit') {
      colorSupport = 'truecolor';
    } else if (term.includes('256color') || colorterm === '256') {
      colorSupport = '256';
    } else if (isTTY) {
      colorSupport = 'basic';
    }
  }
  
  // Detectar soporte de Unicode
  const unicodeSupport = isTTY && !ci && 
    (term.includes('utf') || term.includes('unicode') || process.platform !== 'win32');
  
  return {
    isTTY,
    noColor,
    ci,
    colorSupport,
    unicodeSupport,
    width: process.stdout.columns || 80,
    height: process.stdout.rows || 24
  };
}
```

### **Fase 8: Validaciones**

#### **8.1 Validaciones Obligatorias:**

```typescript
function validateGlyphCatalog(font: Font): ValidationResult {
  const errors: string[] = [];
  const heights = new Set<number>();
  
  for (const [char, glyph] of Object.entries(font)) {
    // Verificar que todas las filas tengan el mismo ancho
    const widths = new Set(glyph.rows.map(r => r.length));
    if (widths.size > 1) {
      errors.push(`Glifo '${char}' tiene filas de ancho inconsistente: ${[...widths].join(', ')}`);
    }
    
    // Registrar altura
    heights.add(glyph.rows.length);
  }
  
  // Verificar que todos los glifos tengan la misma altura
  if (heights.size > 1) {
    errors.push(`Fuente tiene alturas inconsistentes: ${[...heights].join(', ')}`);
  }
  
  // Verificar caracteres requeridos
  const required = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789 ';
  for (const char of required) {
    if (!font[char]) {
      errors.push(`Falta glifo para carácter requerido: '${char}'`);
    }
  }
  
  return {
    valid: errors.length === 0,
    errors
  };
}
```

#### **8.2 Validación de Configuración:**

```typescript
function validateConfig(config: BannerConfig): ValidationResult {
  const errors: string[] = [];
  
  // Validar texto
  if (!config.text || config.text.length === 0) {
    errors.push('El texto del banner no puede estar vacío');
  }
  
  // Validar fuente
  if (!getFont(config.font)) {
    errors.push(`Fuente desconocida: ${config.font}`);
  }
  
  // Validar animación
  const validAnimations = ['none', 'typewriter', 'fade', 'slide', 'wave', 'block'];
  if (config.animation && !validAnimations.includes(config.animation)) {
    errors.push(`Animación inválida: ${config.animation}`);
  }
  
  // Validar velocidad
  if (config.speed !== undefined && (config.speed < 0 || config.speed > 1000)) {
    errors.push('La velocidad debe estar entre 0 y 1000 ms');
  }
  
  // Validar maxWidth
  if (config.maxWidth !== undefined && config.maxWidth < 20) {
    errors.push('El ancho máximo debe ser al menos 20 caracteres');
  }
  
  return {
    valid: errors.length === 0,
    errors
  };
}
```

```typescript
  registerFont(name: string, font: Font): void {

  registerGlyphs(fontName: string, glyphs: Record<string, string[]>): void {

    for (const [char, rows] of Object.entries(glyphs)) {
      font[char] = { char, rows, width: rows[0].length, height: rows.length };
    }
  }

    // Los iconos se almacenan como glifos multi-carácter

  }
}
```

### **Conclusión:**

Esta skill resuelve el problema fundamental de generar banners en aplicaciones CLI: **el agente ya no tiene que inventar letras**. Con el catálogo completo de glifos (A-Z, a-z, 0-9, símbolos, acentos) y múltiples fuentes predefinidas, cualquier texto puede convertirse en un banner ASCII profesional en segundos.

La skill es **complementaria** a la skill anterior de "Banners" (que definía el concepto y los tipos de banners), pero esta vez proporciona la **implementación concreta** con el alfabeto completo que faltaba. El agente puede ahora generar banners para nombres como `IMG2PDF`, `FLARE-DF`, `MY-CLI`, o cualquier otro texto personalizado, sin tener que dibujar las letras manualmente.

La combinación de motor de composición, sistema de temas, animaciones, detección de terminal, validaciones exhaustivas y extensibilidad convierte a esta skill en una solución **enterprise-grade** para generación de banners que puede reutilizarse en cualquier aplicación CLI, manteniendo consistencia visual y calidad profesional en todos los proyectos del ecosistema.
