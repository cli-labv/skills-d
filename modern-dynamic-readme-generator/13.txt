## Skill: Modern Dynamic README Generator - Generador Inteligente de Documentación Adaptativa

**Descripción General:**
Implementar una skill global y reutilizable llamada **Modern Dynamic README Generator** que transforme la plantilla estática de `othneildrew/Best-README-Template` en un generador inteligente de documentación que analice automáticamente el repositorio y construya un `README.md` moderno, visual, completo y adaptado al proyecto; la skill debe detectar el nombre, descripción, lenguaje principal, frameworks, dependencias, comandos de instalación, archivos importantes, licencia, versión, scripts, estructura de carpetas, pruebas, despliegue, contribuciones, enlaces y características desde archivos como `Cargo.toml`, `package.json`, `pyproject.toml`, `Dockerfile`, `Makefile`, workflows de GitHub Actions y documentación existente, y después generar una portada centrada con logo o imagen del proyecto, título, subtítulo, descripción breve, enlaces de documentación, demo, reporte de errores y solicitud de funcionalidades, además de una fila configurable de badges dinámicos para estrellas, forks, issues, pull requests, versión, licencia, cobertura, build, release, lenguaje, dependencias, descarga, estado de CI y actividad del repositorio; debe reutilizar la organización del proyecto de referencia mediante secciones como "Sobre el proyecto", imagen o captura principal, tecnologías utilizadas, requisitos previos, instalación, configuración, uso, ejemplos de comandos, API, arquitectura, estructura de directorios, estados del proyecto, roadmap con casillas, contribución, autores, licencia, agradecimientos, soporte y enlaces de regreso al inicio, utilizando tabla de contenidos automática con `<details>` o enlaces Markdown; debe incluir un sistema de componentes reutilizables para insertar emojis e iconos coherentes según el contexto —por ejemplo 🚀 para instalación, ⚙️ para configuración, 📦 para dependencias, 🧪 para pruebas, 🐳 para Docker, 🔐 para seguridad, 📊 para métricas, 🗺️ para roadmap, 🤝 para contribuciones, 📄 para licencia y 🛠️ para desarrollo—, permitiendo seleccionar un estilo visual profesional, tecnológico, minimalista, colorido, oscuro o corporativo; debe aceptar parámetros como `project_name`, `description`, `repository_url`, `logo`, `screenshots`, `demo_url`, `documentation_url`, `license`, `author`, `language`, `frameworks`, `installation_commands`, `usage_examples`, `badges`, `theme`, `language`, `include_toc`, `include_roadmap`, `include_contributing`, `include_api`, `include_architecture`, `include_changelog`, `include_security`, `include_docker`, `include_ci_status` y `include_social_links`, y permitir generar el README en español, inglés o formato bilingüe; debe crear automáticamente enlaces de referencia al final del documento para evitar URLs repetidas, validar que las imágenes, badges y enlaces existan, evitar placeholders sin completar, adaptar los comandos al ecosistema detectado, generar bloques de código con el lenguaje correcto, incluir tablas para opciones CLI, variables de entorno, niveles de configuración o compatibilidad, mostrar estados mediante badges y tablas, agregar capturas, GIFs, diagramas Mermaid, ejemplos de salida, arquitectura visual y secciones colapsables para no saturar el documento; también debe ofrecer modos `minimal`, `standard`, `complete` y `showcase`, permitir regenerar solo una sección sin sobrescribir cambios manuales, conservar bloques protegidos mediante marcadores como `<!-- CUSTOM:START -->` y `<!-- CUSTOM:END -->`, detectar contenido existente antes de modificarlo, crear un índice de navegación coherente, verificar encabezados duplicados, corregir enlaces internos, mantener accesibilidad mediante textos alternativos en imágenes, no depender exclusivamente de emojis, utilizar HTML solo cuando aporte compatibilidad visual y producir Markdown válido para GitHub; incluye pruebas para proyectos Rust, JavaScript, Python, Go y aplicaciones Docker, validaciones de badges, imágenes, enlaces, tablas, Mermaid, comandos, traducciones y secciones obligatorias, documentación de configuración, ejemplos de README generados y una política para no inventar características, métricas, licencias, comandos ni estados que no puedan confirmarse en el repositorio, de manera que la skill convierta la plantilla estática de Best-README-Template —que actualmente organiza escudos, logo, descripción, tabla de contenidos, instalación, uso, roadmap, contribución, licencia, contacto y agradecimientos— en un sistema automático capaz de producir READMEs más modernos, dinámicos, visualmente atractivos, informativos y personalizados para cualquier proyecto.

### **Fase 1: Arquitectura del Sistema**

#### **1.1 Componentes Principales:**

**RepositoryAnalyzer (Analizador de Repositorio):**
- Escanea automáticamente el repositorio
- Detecta archivos de configuración (package.json, Cargo.toml, pyproject.toml, etc.)
- Extrae metadatos del proyecto
- Identifica lenguaje principal, frameworks, dependencias
- Detecta scripts, comandos, estructura de carpetas
- Analiza workflows de CI/CD
- Lee documentación existente

**MetadataExtractor (Extractor de Metadatos):**
- Extrae información específica de cada tipo de archivo
- Normaliza datos entre diferentes ecosistemas
- Detecta versión, licencia, autor, descripción
- Identifica dependencias de desarrollo vs producción
- Detecta comandos de instalación, build, test

**BadgeGenerator (Generador de Badges):**
- Crea badges dinámicos basados en datos reales del repositorio
- Soporta shields.io, GitHub Actions, Codecov, etc.
- Valida que los badges tengan datos reales
- Configurable por tipo de proyecto

**SectionBuilder (Constructor de Secciones):**
- Genera secciones individuales del README
- Cada sección es un componente independiente
- Soporta personalización y extensión
- Mantiene consistencia visual

**TemplateEngine (Motor de Plantillas):**
- Combina secciones en el documento final
- Aplica tema visual seleccionado
- Genera tabla de contenidos automática
- Maneja enlaces de referencia

**ContentProtector (Protector de Contenido):**
- Detecta bloques protegidos con marcadores
- Preserva contenido personalizado durante regeneraciones
- Permite ediciones manuales sin pérdida

**Validator (Validador):**
- Verifica enlaces, imágenes, badges
- Detecta placeholders sin completar
- Valida sintaxis Markdown
- Verifica accesibilidad

**I18nManager (Gestor de Internacionalización):**
- Soporte para español, inglés, bilingüe
- Traduce secciones automáticamente
- Mantiene consistencia terminológica

#### **2.2 Detección de Estructura del Proyecto:**

```typescript
interface ProjectStructure {
  root: string;
  src?: string;
  tests?: string;
  docs?: string;
  config?: string;
  scripts?: string;
  examples?: string;
  assets?: string;
  hasMakefile: boolean;
  hasDockerfile: boolean;
  hasCI: boolean;
  hasTests: boolean;
  hasDocs: boolean;
}

function analyzeStructure(repoPath: string): ProjectStructure {
  const structure: ProjectStructure = {
    root: repoPath,
    hasMakefile: fs.existsSync(path.join(repoPath, 'Makefile')),
    hasDockerfile: fs.existsSync(path.join(repoPath, 'Dockerfile')),
    hasCI: fs.existsSync(path.join(repoPath, '.github/workflows')),
    hasTests: detectTests(repoPath),
    hasDocs: fs.existsSync(path.join(repoPath, 'docs'))
  };
  
  // Detectar directorios comunes
  const commonDirs = ['src', 'lib', 'test', 'tests', 'docs', 'config', 'scripts', 'examples', 'assets'];
  for (const dir of commonDirs) {
    if (fs.existsSync(path.join(repoPath, dir))) {
      structure[dir as keyof ProjectStructure] = dir;
    }
  }
  
  return structure;
}
```

#### **2.3 Detección de Comandos:**

```typescript
interface DetectedCommands {
  install: string[];
  build: string[];
  test: string[];
  lint: string[];
  dev: string[];
  start: string[];
  deploy: string[];
}

function detectCommands(metadata: ProjectMetadata): DetectedCommands {
  const commands: DetectedCommands = {
    install: [],
    build: [],
    test: [],
    lint: [],
    dev: [],
    start: [],
    deploy: []
  };
  
  // Node.js
  if (metadata.packageJson) {
    if (metadata.packageJson.scripts?.install) {
      commands.install.push('npm install');
    }
    if (metadata.packageJson.scripts?.build) {
      commands.build.push('npm run build');
    }
    if (metadata.packageJson.scripts?.test) {
      commands.test.push('npm test');
    }
    if (metadata.packageJson.scripts?.lint) {
      commands.lint.push('npm run lint');
    }
    if (metadata.packageJson.scripts?.dev) {
      commands.dev.push('npm run dev');
    }
    if (metadata.packageJson.scripts?.start) {
      commands.start.push('npm start');
    }
  }
  
  // Rust
  if (metadata.cargoToml) {
    commands.build.push('cargo build');
    commands.test.push('cargo test');
    commands.dev.push('cargo run');
  }
  
  // Python
  if (metadata.pyprojectToml) {
    commands.install.push('pip install -e .');
    commands.test.push('pytest');
  }
  
  // Docker
  if (metadata.hasDockerfile) {
    commands.build.push('docker build -t project .');
    commands.start.push('docker run project');
  }
  
  // Makefile
  if (metadata.hasMakefile) {
    commands.build.push('make build');
    commands.test.push('make test');
  }
  
  return commands;
}
```

#### **3.2 Generadores de Secciones:**

**Sección "Sobre El Proyecto":**
```typescript
function generateAboutSection(context: GenerationContext): string {
  const { metadata, i18n } = context;
  
  let section = `## ${i18n.t('about.title')}\n\n`;
  
  if (metadata.description) {
    section += `${metadata.description}\n\n`;
  }
  
  if (metadata.features && metadata.features.length > 0) {
    section += `### ${i18n.t('about.features')}\n\n`;
    for (const feature of metadata.features) {
      section += `- ${feature}\n`;
    }
    section += '\n';
  }
  
  return section;
}
```

**Sección "Instalación":**
```typescript
function generateInstallationSection(context: GenerationContext): string {
  const { metadata, commands, i18n } = context;
  
  let section = `## ${i18n.t('installation.title')}\n\n`;
  
  // Prerrequisitos
  if (metadata.engines || metadata.pythonVersion || metadata.goVersion) {
    section += `### ${i18n.t('installation.prerequisites')}\n\n`;
    
    if (metadata.engines?.node) {
      section += `- Node.js >= ${metadata.engines.node}\n`;
    }
    if (metadata.pythonVersion) {
      section += `- Python >= ${metadata.pythonVersion}\n`;
    }
    if (metadata.goVersion) {
      section += `- Go >= ${metadata.goVersion}\n`;
    }
    section += '\n';
  }
  
  // Comandos de instalación
  section += `### ${i18n.t('installation.steps')}\n\n`;
  
  if (commands.install.length > 0) {
    section += '```bash\n';
    for (const cmd of commands.install) {
      section += `${cmd}\n`;
    }
    section += '```\n\n';
  }
  
  return section;
}
```

**Sección "Uso":**
```typescript
function generateUsageSection(context: GenerationContext): string {
  const { metadata, commands, i18n } = context;
  
  let section = `## ${i18n.t('usage.title')}\n\n`;
  
  if (commands.start.length > 0) {
    section += '```bash\n';
    for (const cmd of commands.start) {
      section += `${cmd}\n`;
    }
    section += '```\n\n';
  }
  
  if (metadata.usageExamples && metadata.usageExamples.length > 0) {
    section += `### ${i18n.t('usage.examples')}\n\n`;
    for (const example of metadata.usageExamples) {
      section += `${example.description}\n\n`;
      section += '```' + (example.language || 'bash') + '\n';
      section += `${example.code}\n`;
      section += '```\n\n';
    }
  }
  
  return section;
}

### **Fase 4: Sistema de Badges Dinámicos**

#### **4.1 Generador de Badges:**

```typescript
interface Badge {
  label: string;
  message: string;
  color: string;
  logo?: string;
  url?: string;
}

function generateBadges(metadata: ProjectMetadata, config: BadgeConfig): string {
  const badges: Badge[] = [];
  
  // Versión
  if (metadata.version) {
    badges.push({
      label: 'version',
      message: metadata.version,
      color: 'blue',
      url: `${metadata.repositoryUrl}/releases/latest`
    });
  }
  
  // Licencia
  if (metadata.license) {
    badges.push({
      label: 'license',
      message: metadata.license,
      color: 'green'
    });
  }
  
  // Lenguaje
  if (metadata.language) {
    const color = getLanguageColor(metadata.language);
    badges.push({
      label: 'language',
      message: metadata.language,
      color: color,
      logo: getLanguageLogo(metadata.language)
    });
  }
  
  // CI Status
  if (metadata.hasCI && config.includeCIStatus) {
    badges.push({
      label: 'build',
      message: 'passing',
      color: 'brightgreen',
      url: `${metadata.repositoryUrl}/actions`
    });
  }
  
  // Coverage
  if (metadata.hasTests && config.includeCoverage) {
    badges.push({
      label: 'coverage',
      message: 'unknown',
      color: 'yellow',
      url: `${metadata.repositoryUrl}/actions`
    });
  }
  
  // Stars
  if (config.includeStars) {
    badges.push({
      label: 'stars',
      message: '⭐',
      color: 'yellow',
      url: `${metadata.repositoryUrl}/stargazers`
    });
  }
  
  // Forks
  if (config.includeForks) {
    badges.push({
      label: 'forks',
      message: '🍴',
      color: 'lightgrey',
      url: `${metadata.repositoryUrl}/network/members`
    });
  }
  
  // Issues
  if (config.includeIssues) {
    badges.push({
      label: 'issues',
      message: '🐛',
      color: 'red',
      url: `${metadata.repositoryUrl}/issues`
    });
  }
  
  // Renderizar badges
  return badges.map(badge => {
    const imgUrl = `https://img.shields.io/badge/${badge.label}-${badge.message}-${badge.color}`;
    const logoParam = badge.logo ? `&logo=${badge.logo}` : '';
    const fullUrl = `${imgUrl}?style=flat-square${logoParam}`;
    
    if (badge.url) {
      return `[![${badge.label}](${fullUrl})](${badge.url})`;
    }
    return `![${badge.label}](${fullUrl})`;
  }).join(' ');
}
```

### **Fase 7: Protección de Contenido Personalizado**

#### **7.1 Sistema de Marcadores:**

```typescript
const CUSTOM_START_MARKER = '<!-- CUSTOM:START';
const CUSTOM_END_MARKER = '<!-- CUSTOM:END -->';

interface ProtectedBlock {
  id: string;
  content: string;
  startLine: number;
  endLine: number;
}

function extractProtectedBlocks(readme: string): ProtectedBlock[] {
  const blocks: ProtectedBlock[] = [];
  const lines = readme.split('\n');
  
  let inBlock = false;
  let currentBlock: Partial<ProtectedBlock> = {};
  
  for (let i = 0; i < lines.length; i++) {
    const line = lines[i];
    
    if (line.includes(CUSTOM_START_MARKER)) {
      const match = line.match(/<!-- CUSTOM:START\s+id="([^"]+)"\s*-->/);
      if (match) {
        inBlock = true;
        currentBlock = {
          id: match[1],
          content: '',
          startLine: i
        };
      }
    } else if (line.includes(CUSTOM_END_MARKER) && inBlock) {
      currentBlock.endLine = i;
      blocks.push(currentBlock as ProtectedBlock);
      inBlock = false;
      currentBlock = {};
    } else if (inBlock) {
      currentBlock.content += line + '\n';
    }
  }
  
  return blocks;
}

function injectProtectedBlocks(readme: string, blocks: ProtectedBlock[]): string {
  let result = readme;
  
  for (const block of blocks) {
    const marker = `${CUSTOM_START_MARKER} id="${block.id}" -->\n${block.content}${CUSTOM_END_MARKER}`;
    
    // Buscar si ya existe el bloque
    const existingPattern = new RegExp(
      `${CUSTOM_START_MARKER} id="${block.id}"[\\s\\S]*?${CUSTOM_END_MARKER}`,
      'g'
    );
    
    if (result.match(existingPattern)) {
      // Reemplazar contenido existente
      result = result.replace(existingPattern, marker);
    } else {
      // Insertar al final
      result += '\n\n' + marker;
    }
  }
  
  return result;
}
```

### **Fase 8: Validaciones**

#### **8.1 Validación de Enlaces:**

```typescript
async function validateLinks(readme: string): Promise<ValidationResult> {
  const errors: string[] = [];
  const warnings: string[] = [];
  
  // Extraer todos los enlaces
  const linkPattern = /\[([^\]]+)\]\(([^)]+)\)/g;
  const matches = [...readme.matchAll(linkPattern)];
  
  for (const match of matches) {
    const url = match[2];
    
    // Verificar que no sea un placeholder
    if (url.includes('your-') || url.includes('example.com') || url.includes('TODO')) {
      warnings.push(`Enlace con placeholder detectado: ${url}`);
      continue;
    }
    
    // Verificar formato de URL
    if (!url.startsWith('http') && !url.startsWith('#') && !url.startsWith('mailto:')) {
      // Puede ser un enlace relativo
      if (!url.startsWith('./') && !url.startsWith('../')) {
        warnings.push(`Enlace relativo sin ./ o ../: ${url}`);
      }
    }
    
    // Para URLs externas, verificar que sean accesibles (opcional)
    if (url.startsWith('http')) {
      try {
        const response = await fetch(url, { method: 'HEAD' });
        if (!response.ok) {
          errors.push(`Enlace roto: ${url} (status: ${response.status})`);
        }
      } catch (e) {
        warnings.push(`No se pudo verificar enlace: ${url}`);
      }
    }
  }
  
  return {
    valid: errors.length === 0,
    errors,
    warnings
  };
}

async function validateImages(readme: string): Promise<ValidationResult> {
  const errors: string[] = [];
  const warnings: string[] = [];
  
  // Extraer todas las imágenes
  const imagePattern = /!\[([^\]]*)\]\(([^)]+)\)/g;
  const matches = [...readme.matchAll(imagePattern)];
  
  for (const match of matches) {
    const alt = match[1];
    const url = match[2];
    
    // Verificar que tenga texto alternativo
    if (!alt || alt.trim() === '') {
      warnings.push(`Imagen sin texto alternativo: ${url}`);
    }
    
    // Verificar que no sea un placeholder
    if (url.includes('placeholder') || url.includes('your-') || url.includes('example.com')) {
      errors.push(`Imagen con placeholder: ${url}`);
      continue;
    }
    
    // Verificar formato
    if (!url.match(/\.(png|jpg|jpeg|gif|svg|webp)$/i)) {
      warnings.push(`Imagen con formato no estándar: ${url}`);
    }
  }
  
  return {
    valid: errors.length === 0,
    errors,
    warnings
  };
}

// Generar README completo
async function generateREADME(options: READMEOptions): Promise<string> {
  // 1. Analizar repositorio
  const metadata = await analyzeRepository(options.repositoryPath);
  
  // 2. Extraer metadatos
  const extractedMetadata = await extractMetadata(metadata);
  
  // 3. Detectar comandos
  const commands = detectCommands(extractedMetadata);
  
  // 4. Crear contexto de generación
  const context: GenerationContext = {
    metadata: extractedMetadata,
    commands,
    config: options,
    i18n: new I18nManager(options.language)
  };
  
  // 5. Generar secciones
  const sections = generateSections(context, options.mode);
  
  // 6. Generar badges
  const badges = generateBadges(extractedMetadata, options.badges);
  
  // 7. Generar header
  const header = generateHeader(context, badges);
  
  // 8. Generar tabla de contenidos
  const toc = options.includeTOC ? generateTOC(sections) : '';
  
  // 9. Combinar todo
  let readme = `${header}\n\n${toc}\n\n${sections.join('\n\n')}`;
  
  // 10. Proteger contenido personalizado
  if (options.preserveCustom) {
    const existingReadme = await readExistingREADME(options.repositoryPath);
    const protectedBlocks = extractProtectedBlocks(existingReadme);
    readme = injectProtectedBlocks(readme, protectedBlocks);
  }
  
  // 11. Validar
  const validation = await validateREADME(readme);
  if (!validation.valid) {
    console.warn('README validation warnings:', validation.warnings);
  }
  
  return readme;
}

// Regenerar solo una sección
async function regenerateSection(
  readmePath: string,
  sectionId: string,
  options: Partial<READMEOptions>
): Promise<string> {
  const existingReadme = await fs.readFile(readmePath, 'utf-8');
  const metadata = await analyzeRepository(options.repositoryPath || '.');
  const context = createGenerationContext(metadata, options);
  
  const section = SECTION_COMPONENTS.find(c => c.id === sectionId);
  if (!section) throw new Error(`Sección no encontrada: ${sectionId}`);
  
  const newSection = section.generator(context);
  
  // Reemplazar sección en el README existente
  return replaceSection(existingReadme, sectionId, newSection);
}

// Validar README existente
async function validateREADME(readme: string): Promise<ValidationResult> {
  const linkValidation = await validateLinks(readme);
  const imageValidation = await validateImages(readme);
  const badgeValidation = validateBadges(readme);
  
  return {
    valid: linkValidation.valid && imageValidation.valid && badgeValidation.valid,
    errors: [...linkValidation.errors, ...imageValidation.errors, ...badgeValidation.errors],
    warnings: [...linkValidation.warnings, ...imageValidation.warnings, ...badgeValidation.warnings]
  };
}
